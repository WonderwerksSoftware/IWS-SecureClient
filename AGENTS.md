# IWS project agreement

## Product contract
Build on the working IWS system. Improve presentation and extend behavior intentionally; do not substitute a rewrite or generic ERP. Approved visual references and source assets are specifications, not inspiration.

Employees install and use one application: IWS. Connectivity provisions automatically through ordinary installation and unavoidable OS approvals. Employees do not operate another networking product, create third-party VPN accounts, enter keys/addresses, configure DNS/certificates, or manage tunnels. Preserve private HTTPS with IWS-controlled DNS/CA, validated certificates, centrally revocable access, isolation, and normal networking for unrelated apps. Infrastructure convenience never silently changes this experience.
