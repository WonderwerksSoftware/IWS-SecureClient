# IWS client branding

These are the accepted shared native-client mark assets from the Windows
productization checkpoint. Android retains platform-native vector/adaptive-icon
derivatives under `android/app/src/main/res/`.

`iws-icon-source.svg` is the canonical transparent small mark. The Windows ICO
remains under `windows/webview2/assets/` because it is a platform-specific
compiled resource.
